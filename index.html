LibRE SigmaScientific Statistical Analysis & Reliability Engineering

The open-source, local-first platform for Six Sigma, SPC control charts, Taguchi DOE, and Weibull life data analysis. A modern, free alternative to Minitab and JMP.

Get Started
Explore Capabilities
GitHub
📊

120+ Statistical Analysis Plugins

Complete inferential suite powered by NumPy, SciPy, Statsmodels, Scikit-Learn, and Lifelines. Includes ANOVA, GLM, Nonparametrics, and Time Series.

🎯

Six Sigma & SPC Quality Control

Variables & Attributes Control Charts (Xbar-R, I-MR, p, u), automated 8 Nelson zone rule detection, and Capability Sixpack (Cp, Cpk, Pp, Ppk).

🧪

Industrial Design of Experiments

Taguchi Orthogonal Arrays (L4-L27) with S/N ratios, 2^k Full and Fractional Factorials, Central Composite (CCD), Box-Behnken, and Mixture designs.

⏳

Reliability & Life Data Analysis

Parametric Weibull (2P/3P), Lognormal, Exponential fitting with MLE, plus non-parametric Kaplan-Meier survival curves and B10/B50 life estimation.

⚡

High-Performance Canvas Spreadsheet

Dual-header grid with named variables, formula evaluation (LN, STANDARDIZE), multi-sheet tabs, and sub-millisecond 60 FPS rendering.

🔒

100% Local-First & Zero Telemetry

Zero cloud dependency, zero data transmission, and zero telemetry. All computations execute directly on your local machine with full privacy.

LibRE Sigma Desktop Interface: Project Navigator, Interactive Xbar-R Control Charts, Process Capability Sixpack, and Multi-Sheet Data Grid

Quick Start (1-Step Launch) ​

Run LibRE Sigma instantly across Windows, macOS, or Linux using the universal launcher:

bash
# 1. Clone the repository
git clone https://github.com/A-K-T-K/libre-sigma.git
cd libre-sigma

# 2. Launch universal desktop application
python start.py
